# 2026-county-board-elections
A straightforward web map for 2026 county board elections. Mostly vibecoded.

https://epaulson.github.io/2026-county-board-elections/


To build it
```
npm install
npm run dev
```

2024 election results are from LTSB. 
LTSB disaggregates over reporting units which don't always nicely line up with county board districts, so the result percentages aren't perfect (and can't be, because of the way election reporting rollups work  in WI), but they're not that far off.
